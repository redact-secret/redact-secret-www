## Cutover

The header `Docs` link resolves to `/docs/`. `Integrations` remains a separate
marketing-page destination. Canonical and hreflang metadata are emitted for
every docs route, and all routes are included in `sitemap.xml`.

## Rollback

Roll back the application release through the existing site release workflow.
Because docs routes, shell navigation, renderer inputs, schemas, and copy ship
in one application artifact, do not roll back only the header link or only
`docs.json`. A complete prior application release restores the previous route
registry and output set atomically. Content-only rollback is safe only between
content releases that target the same renderer API and include `docs.json`.
